## Project: Hosting Website on AWS EC2

### Services Used
- EC2
- Security Groups
- Nginx
- IAM

### Steps Performed
1. Launched EC2 instance
2. Configured security group (SSH, HTTP)
3. Installed and configured Nginx
4. Hosted static website
5. Verified using public IP

 Why Use EC2 Instead of S3 for Static Website Hosting?
 Both Amazon S3 and Amazon EC2 can be used to host static websites. However, EC2 is chosen in certain real-world scenarios where more control, flexibility, and server-level access are required.
